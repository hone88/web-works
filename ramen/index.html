広島のラーメンらしく、もやしとねぎをたっぷり。スープの色は濃いですが、後味は軽めです。

  1. 1醤油ダレ濃口と再仕込みの、2種類の醤油を合わせています。
  2. 2スープ豚骨と鶏ガラを12時間。毎朝6時から炊いています。
  3. 3麺細いストレート麺。スープがよく絡むよう、加水を低めにしています。
  4. 4チャーシュー豚バラを巻いて煮たあと、注文ごとに炙ります。
  5. 5もやし・ねぎ・メンマ広島の中華そばの定番。ねぎは増量もできます。

    設計メモ｜券売機メニュー

    はじめてのラーメン店で一番緊張するのが券売機の前。実機と同じ色分けでメニューを並べ、押すと丼の具と食券が変わる体験にしました。「麺のかたさの言い方」まで先に分かるので、来店前の不安がひとつ減ります。色だけでなく見出しでも区別しています。

    設計メモ｜選ばれる理由

    ラーメン店のクチコミは「時間」「味」「入りやすさ」の3つに集まりやすいので、それぞれを数字1つで言い切る構成にしました。数字は実案件では店主への聞き取りで確認します。

    お客さまの声

    食べた方は、こう書いてくださっています

    このサンプルのクチコミは架空です。実際の制作では、Googleマップ等の実際の投稿から許可の範囲で抜粋します。

    混む時間

    並ばずに入るなら、11時台か14時前

    昼は12時台、夜は22時台が混みます。夜の22時台は、近くの飲み屋帰りのお客さまが増える時間です。

    設計メモ｜混む時間

    「並ぶのが嫌で行かない」を減らすためのグラフです。今の時間帯の棒に「いま」の印が付きます。実案件ではGoogleマップの混雑状況と店主の感覚をすり合わせて作ります。

    はじめての方へ

    入ってから食べるまで、この4つだけ

    1. 入口の券売機で食券を買うラーメンを1枚、トッピングやサイドは追加で。現金と交通系ICが使えます。
    2. 空いている席に座る一人ならカウンター、2名以上ならテーブルへどうぞ。
    3. 食券をカウンターに出すこのとき、麺のかたさや味の濃さを伝えてください。
    4. 食べ終わったら、そのままどうぞ丼はカウンターの上に置いたままで大丈夫です。

    お子さま連れ

    テーブル席2卓。取り分け用のお椀と子ども用フォークがあります。

    駐車場

    店の隣に3台。満車のときは近くのコインパーキングをご利用ください。

    替え玉・ライス

    替え玉はありません。麺を多めにしたい方は「大盛」の食券をどうぞ。

    よくある質問

    よくいただく質問

    麺のかたさは何種類ありますか？

    バリカタ・カタ・普通・やわめの4種類です。食券を出すときにお伝えください。

    スープがなくなって早く閉まることはありますか？

    週末の夜は、22時過ぎにスープがなくなり早めに閉めることがあります。その日はInstagramでお知らせします。

    持ち帰りはできますか？

    餃子（生・焼き）はお持ち帰りできます。ラーメンはお店でお召し上がりください。

    キャッシュレスは使えますか？

    券売機で現金と交通系ICが使えます（サンプル表記）。

    ここから先は、このサイトをつくった人の話です

    お店の空気を、そのままWebに。

    ゆうきです。広島で、お店ごとに一から設計するWebサイトをつくっています。このページはラーメン屋を想定した制作サンプルです。同じ「飲食店」でも、ラーメン屋なら券売機と深夜営業、海鮮食堂なら仕入れと品書き、というように、その業種のお客さんが知りたいことから組み立てます。

    制作サンプル

    海鮮食堂編のれんの藍と品書き。日替わり定食と季節の魚を中心に。 ラーメン屋編このページ券売機を練習できるメニュー、混む時間のグラフ。

    このサンプルに入っている仕組み

    • 券売機メニュー押すと丼の具・食券・合計が変わる体験型メニュー
    • 営業中を自動表示曜日と時刻で「営業中／準備中／定休日」を切り替え
    • 混雑時間のグラフ今の時間帯に「いま」の印が付く
    • 丼の断面図番号で図と説明をつなぎ、スマホでも読める
    • ダークモード対応夜に開いてもまぶしくない配色に自動で切り替え
    • 誰でも使える作りキーボード操作・読み上げ・動きを減らす設定に対応

    つくり方

    1. 話を聞く・クチコミを読むお店の歴史、自慢、よく聞かれる質問。クチコミは全件読みます。
    2. 設計する誰に何を伝えるか、どの順番で見せるかを決めます。
    3. つくって、確かめるスマホ・PC・夜の表示で確認し、直してからお渡しします。
    4. 公開して育てるメニューや季節の更新もご相談ください。
